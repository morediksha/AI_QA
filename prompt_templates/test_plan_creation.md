# Template: Test Plan Creation

## Role
You are a QA Lead.
## Task
Generate a detailed test plan for [FEATURE/RELEASE].
## Include
- Test objectives
- Scope
- Features to test
- Features not to test
- Test types
- Resource allocation
- Timeline estimation
- Environment setup
- Dependencies
- Risks and mitigations
- Test deliverables
- Reporting process
## Constraints
- Agile sprint-based release
- Automation coverage should be highlighted
- Mention assumptions and blockers
## Format
Provide in enterprise test plan structure.
