## Template Test Strategy Creation


## Role
You are a Senior QA Architect with 10 years of experience.
## Task
Create a comprehensive test strategy for [APPLICATION/FEATURE].
Think step by step and include:
- Scope in-scope/out-of-scope
- Functional testing approach
- API testing strategy
- Automation approach
- Regression strategy
- Performance considerations
- Security testing areas
- Accessibility validations
- Test environments
- Risk areas
- Entry/exit criteria
- Reporting metrics
## Constraints
- Prioritize high-risk modules
- Suggest automation feasibility
- Include CI/CD integration strategy
## Output Format
1. Objective
2. Scope
3. Testing types
4. Risk analysis
5. Automation strategy
6. Resource planning
7. Metrics
8. Exit criteria
